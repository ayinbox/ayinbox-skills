# Security

Report a vulnerability in these skills, or in the AY Inbox service they drive, by email to
team@ayinbox.com. Do not open a public issue for a vulnerability.

Include what you found, how to reproduce it, and what an attacker could do with it. We will
answer, keep you informed while we fix it, and credit you if you want.

These skills never ask for an API key in chat. If a skill or a fork of one tells an agent to
paste, print or commit a credential, report it.
